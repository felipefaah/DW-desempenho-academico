# DW-desempenho-academico

# 📊 Data Warehouse para Análise de Desempenho e Retenção Acadêmica

Este Data Warehouse consiste em uma solução analítica focada no acompanhamento de notas, taxa de faltas, evasão e gargalos curriculares de estudantes em disciplinas universitárias.

## 📌 Objetivos do Projeto
- **Modelagem Dimensional:** Construção de um esquemas estrela (Star Schema) focado na granularidade de matrículas por aluno/disciplina.
- **Consultas Analíticas:** Exploração em linguagem natural e SQL para identificação de disciplinas críticas e taxas de retenção.
- **Visualização de Dados:** Construção de dashboards interativos argumentados para suporte à gestão acadêmica.
- **Carga de Dados Sintéticos:** Povoamento do modelo para validação das métricas e prototipação dos painéis
